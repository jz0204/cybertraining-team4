# LA 优先的用途分类适配实验

2026-10-29。用户授权复核标签、补充隔离训练样本、优先改进 CNN，并以同样数据运行 DINO 对照；效果不足时继续诊断识别方法。使用现有 stage2a 数据与训练工具，不修改线上分类器。

## 要回答的问题

1. 增加空间隔离、与测试成像条件接近的 LA 训练样本，能否提高已有 CNN 的 LA macro-F1，尤其是多户和商业识别？
2. 在相同适配训练记录、输入文件和更新预算下，DINO 是否比继续使用 CNN 更有价值？两者预训练/初始化历史不同，因此是实用方案比较，不宣称纯骨干因果对照。

## 数据和标签

- 保留完整 3,332 条旧 LA 参考及 3,157 条成对原生视图可用子集的原始结果。主报完整集，另报固定共同子集；不把输入缺失从分母移除。
- 已检查全部 14 多户、42 商业，以及 1 个小住宅用途代码/Units 冲突；参考标签保持不变。多条 assessor building record、历史轮廓不一致和疑似局部屋顶轮廓分别列出，不因模型答错而改标。复核表不是人工独立金标准。
- 新数据使用 2024 assessor，用途定义复用 `evaluate_assessor.map_use`。LA `Units` 不等于 NYC `unitsres`，商业非零 Units 本身不构成混合住宅证据。
- 从原产品的全部 126 个 cell 建筑范围、冻结测试宽视野范围外扩 2 km 建立排除区。新增完整宽视野须与排除区不相交，地块不得与测试重复。
- 使用 2 km 网格的固定 hash 划分 train/val/reserved；完整上下文须位于所属网格内。reserved 不提取影像、不运行模型。固定划分不根据模型结果改变。
- 参考纳入条件：一个 assessor building record、正建筑面积、住宅 Units 与类别一致；县域 2014 轮廓恰好一个；同一 BLD_ID 在 2020 唯一匹配且 IoU>=0.8。只选覆盖整个上下文的火灾前 Maxar scene，检查缺失像素和目标保留率。
- 初步通过属性/轮廓门槛的 1,186 个候选：train 478/93/177，val 220/127/91（small/multi/commercial）。最终数量以影像 QA 与冻结 manifest 为准，不为凑数放宽规则。
- 小住宅获取采用 OBJECTID 每 20 条取 1 条，少数类完整获取给定边界内的合格记录；这些候选数不是自然人口比例。训练候选有上限，验证候选不截断；验证同时报告原始 macro-F1 与 small 权重 20、其余权重 1 的采样校正 macro-F1。后者用于选 checkpoint，权重来自获取设计，不来自测试标签比例。
- 新训练配合原 N2 的 13,911 条 Harris+NYC train；不使用原 Harris val/test 训练。两模型共享精确 ID。没有用途/角色真值的五类扩展在此不计分。

## 首轮训练设置（读取测试新结果前固定）

| 项目 | CNN | DINO |
|---|---|---|
| 初始化 | 既有 N2 对应种子 checkpoint | 已缓存官方 DINOv3 ViT-B/16 |
| 输出 | LA 三类 | LA 三类 |
| 输入 | 与原 CNN 一致的 RGB/mask crop、四项几何量 | 相同 crop/mask/几何量；RGB 输入 DINO，mask 用于池化 |
| 池化/分类器 | 原 N2 的 area-mask pooling 与分类头 | area-mask pooling，复用同一分类头结构 |
| 可训练部分 | CNN 与分类头；人口头不训练 | 最后两个 transformer block 与分类头；人口头不训练 |
| 学习率 | 1e-5 | backbone 2e-5，分类头 1e-3 |
| 优化 | AdamW，weight_decay .01，梯度范数上限1.0 | 相同 |
| 数据抽样 | 原 source 与新增 LA 各占抽样质量一半，域内自然抽样 | 相同 |
| 预算 | 每 epoch 8,192 draws，batch32，最多6epoch | 相同 |
| 随机种子 | 42、43 | 42、43 |
| 选 checkpoint | 隔离 LA val 的采样校正 macro-F1；CNN 包含 epoch0 | 相同；不看旧 LA test 来选择 epoch/阈值 |
| 增强 | 与原数据工具一致的水平翻转和90度旋转 | 相同 |

本轮首先保持原 CNN 的单近景推理接口；新数据同时保存完整目标近景/宽视野用于 QA 和后续诊断。测试复用原 crop，避免把目标适配、换图与覆盖率变化混为同一个增益。若旧 crop 或运行环境无法复现原 CNN 基线，先修正输入，再训练。

## 验收与后续分支

- 主结果：完整 3,332 的 accuracy/macro-F1、每类 precision/recall、混淆矩阵及覆盖率；共同 3,157、原 strict-assessor 和本次审计不确定性子集作敏感性分析。
- 既有完整集 CNN N2 概率集成为 accuracy .958283 / macro-F1 .483279；共同集 .963573 / .504806。新结果分别与同分母旧预测配对。
- 各种子结果与概率平均都报告；以空间 cell 配对 bootstrap 检查 macro-F1 差值，不把两种子视为独立城市。多户仅14个，须同时给出判对数和误报数。
- 如果开发验证无提升，保留 epoch0，记录失败；不反复根据测试集换阈值。若新测试仍失败，先检查错误是否集中在四单元、局部轮廓或相似屋顶，再决定补更多独立低层多户样本或加真实上下文。只有证据支持时才增加模型结构。
- 当前 LA 已多次查看，属于开发回归证据。reserved LA 区域须在方案锁定后另作最终验证；不宣称这轮已证明跨城市泛化。

## 执行与算力

标签审计 → 新数据影像 QA/空间自检/冻结 → CNN 原预测复现与真实 GPU backward 检查 → CNN 两种子 → DINO 两种子 → 收集与配对分析。

使用现有 TAMU A30、模型缓存和隔离输出目录。当前检查 root/home 剩余约15/13GiB，原服务均1/1；新原始影像存外置盘，仅上传必要训练 crop。GPU 批次沿用已授权的临时服务暂停与自动恢复，单批最多90分钟，并在训练前测量实际显存和步速、完成后验证服务恢复。CPU 数据准备期间不暂停服务。
