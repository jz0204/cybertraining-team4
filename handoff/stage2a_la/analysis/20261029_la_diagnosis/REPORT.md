# LA 优先：现有模型的具体问题

2026-10-29。用户将当前目标明确为提高 LA test dataset 上的效果。本轮仅复算已保存预测、核查训练配置和参考属性、检查既有图像；没有训练、重新推理、修改参考标签或操作远程服务。

结论：目前应优先解决多户住宅识别、商业误报/漏报，以及训练数据和 LA 任务不匹配。高整体 accuracy 尚不代表三类都识别良好。继续扩大 QLoRA 或评估另一城市，应排在这些问题之后。

## 1. 同一批 LA 数据上的实际结果

完整参考集 3,332 栋：小型住宅 3,276、多户住宅 14、商业 42。原生近景和宽视野均可用的共同子集为 3,157 栋：小型住宅 3,101、多户住宅 14、商业 42。下表使用该共同子集，macro-F1 对三个 LA 参考类别取平均；五类模型输出 institutional/other/unknown 均计为错误。这是给定建筑轮廓的分类评估，不是建筑检测 AP。

| 方法 | Accuracy | Macro-F1 | 多户判对 | 商业判对 |
|---|---:|---:|---:|---:|
| 全部预测小型住宅的诊断基线 | 98.23% | 0.3304 | 0/14 | 0/42 |
| CNN N2，两种子概率平均 | 96.36% | 0.5048 | 2/14 | 31/42 |
| Qwen NF4 zero-shot | 98.64% | 0.5263 | 0/14 | 19/42 |
| DINO A，仅 NYC，种子 42 / 43 | 5.00% / 7.48% | 0.1334 / 0.1053 | 10/14 / 11/14 | 10/42 / 4/42 |
| DINO B，多城，种子 42 / 43 | 60.63% / 64.24% | 0.4344 / 0.4523 | 6/14 / 3/14 | 15/42 / 14/42 |
| Qwen QLoRA，种子 42 / 43 | 45.87% / 60.53% | 0.4276 / 0.3853 | 6/14 / 5/14 | 24/42 / 11/42 |

Qwen zero-shot 相比全部预测小型住宅，净减少 13 个错误，但仍漏掉全部多户住宅。其相对 CNN 的 macro-F1 差值为 +0.0215，既有同样本空间 bootstrap 95% 区间为 [-0.0728, 0.1353]，尚不能认为优势稳定。区间来自既有 `20261028_la_transfer/QWEN_ZERO_PAIRED.json`。

完整 3,332 栋上，CNN 为 **95.83% / 0.4833**，Qwen zero-shot 为 **93.46% / 0.5173**（accuracy / macro-F1）。不得用共同子集的 98.64% 代替完整 LA 结果。

## 2. CNN 与 Qwen 卡在不同的地方

| 共同子集上的错误 | CNN N2 | Qwen zero-shot |
|---|---:|---:|
| 小型住宅判错 | 92/3,101 | 6/3,101 |
| 多户 precision / recall | 8.33% / 14.29% | 0 / 0 |
| 商业 precision / recall | 30.10% / 73.81% | 82.61% / 45.24% |

CNN 商业召回较好，但 70 栋小型住宅被判为商业、22 栋被判为多户。Qwen 很少误报商业，但漏掉 23/42 商业，并且没有输出过多户类别。QLoRA 则出现大量反方向错误：种子 42 将 1,464 栋小型住宅判为多户，种子 43 为 766 栋。

简单投票难以补齐多户识别：CNN 和 Qwen 同时判错 12/14 多户，Qwen 没有独立判对的多户。商业中有 13 栋 CNN 判对而 Qwen 判错，若让 Qwen 一律否决 CNN 的商业预测，会损失这些正确结果。融合仍可作为开发集实验，但不能先假定它能解决当前问题。

## 3. 五类任务错配解释了部分 DINO 失败，但不是全部

多城 DINO 的种子 42 / 43 分别把 **977 / 1,044 栋小型住宅判成 institutional**。本轮只重读已保存的五类概率，限定在三个 LA 类别内取 argmax；没有更新模型或使用参考标签选择每栋预测。

| 两种子指标平均，3,157 栋 | 原五类输出 Accuracy / F1 | 限定三类读出 Accuracy / F1 |
|---|---:|---:|
| NYC DINO | 6.24% / 0.1194 | 6.86% / 0.1718 |
| 多城 DINO | 62.43% / 0.4433 | 81.55% / 0.4651 |

多城 accuracy 上升 19.12 个百分点，macro-F1 仅上升 0.0218。限定三类后，种子 42 / 43 仍有 **687 / 351 栋小型住宅被判为多户**。仅修改输出类别并不能修复该边界。

多城原输出的种子间 sample SD 为 accuracy 2.55 个百分点、macro-F1 0.0126；三类读出分别为 7.06 个百分点、0.0013。仅两个种子，不能据此推断稳定性。完整种子统计见 `DIAGNOSIS.json`。

**三类读出属于看过 LA 结果后的诊断，假设目标只包含 LA 的三个类别；它不能识别 institutional/other，也不是独立验证的新模型。** 若最终仍要求五类与主/附属标记，应保留该任务，并另外建设可靠的五类/角色验证集；当前 LA 参考集没有后两类和角色真值。

## 4. 当前结果不是公平的 CNN 与基础模型骨干对照

| 项目 | CNN N2 | 新 DINO / Qwen 微调 |
|---|---|---|
| 训练样本 | 13,333 Harris + 578 NYC，共 13,911 | 720，其中 600 有五类用途标签，120 为用途缺失的附属建筑记录 |
| 类别/训练来源 | 三类；自然采样 | 五类各 120；另有 120 附属记录；A/Qwen 为 NYC，B 为 NYC/Cambridge/Seattle |
| 输入 | RGB + mask + 四项几何量，224 px；含尺度视图训练 | 目标近景 + 宽视野，五类用途与二类角色任务 |
| 模型 | ConvNeXt-Tiny | DINOv3 ViT-B/16，或 Qwen3-VL-8B QLoRA |

N2 的 `nyc_natural` 名称容易造成误解：它不是只用 NYC 训练。实际训练 CSV 的 train 行数为 13,911。新微调仅有约 1/19 的训练记录，已知用途记录更少；标签、影像/轮廓来源、采样与输入也不同。不能根据这一比较宣称 CNN 骨干优于 DINO/VLM。

固定 720 样本和相同训练预算时，多城 DINO 明显优于 NYC DINO，说明训练组成值得改进。但其绝对 LA 效果仍低于已有 CNN/Qwen 基线。当前观察支持优先修数据与任务对齐，不支持继续沿用同一小样本配置扩大 QLoRA。

配置证据：外置盘 `II_package/outputs/stage2a/la_data_20261024/runs/N2_nyc_natural_seed42/train_config.json` 和 `data/N2_nyc_natural_seed42.csv`；新实验协议和完整结果见 `../20261028_multicity_transfer/REPORT.md`。

## 5. LA 的少数类具体是什么，以及图像说明了什么

全部 56 个少数类记录已按 `(cell_id, bldg_uid)` 与既有 assessor 文件逐一匹配，每栋恰好一个匹配；属性与各模型预测见 `MINORITY_CASES.csv`。

- 14 栋多户：9 栋为 4 单元、2 栋为 5 单元、2 栋为 8 单元、1 栋为 26 单元。多数属于低层、小规模多户，不能以大型公寓外观代表整个类别。
- 42 栋商业：8 栋 Office Building、14 栋 Professional Building，其余为商店、餐饮、超市、银行、维修等。办公室/专业用途建筑合计 22/42，并非都具有大型商场的外观。
- 13/14 多户只有一条 assessor building record；另 1 栋四单元有两条，未通过既有 strict-single-building 条件。不能把所有多户错误都解释为多建筑地块匹配错误。

本轮查看三个有代表性的共同错误样本各自的近景与宽视野。选取目的为诊断，不能据此估计全体数据缺陷比例；图像观察也不构成新真值。

| 样本 ID | 参考属性与预测 | 近景/宽视野观察 |
|---|---|---|
| `la_cell_00365_55a82578-7cc5-4b90-bf2a-30249ab337b9` | 4 单元、单 assessor building；CNN/Qwen 均判小住宅 | 屋顶和目标标记清楚，呈普通坡屋顶形态；不是空白图。俯视外观不能直接确认户数。 |
| `la_cell_00366_e2321792-3cd7-4c0a-b9dc-4a1699442192` | 26 单元、单 assessor building；均判商业 | 可见大型重复屋顶结构，目标在两个尺度中可辨，邻近商业/停车环境；不能归因于所有多户都不可见或裁剪过小。 |
| `la_cell_00107_ad66a0b1-06f7-412c-875d-e3cd5363bba2` | Office Building、单 assessor building；均判小住宅 | 小型屋顶清楚，周围有道路与住宅/植被，没有足以直接确认办公用途的明显俯视线索。 |

这些图像已经包含真实宽视野，单纯放大 crop 或改 prompt 不是当前证据支持的首要修复。已有加载器抽查通过 RGB、mask 和张量检查；仍有先前发现的疑似轮廓纳入庭院/泳池或截断屋顶的问题，需逐例核查，尚无总体发生率。预测 polygon 面积不可当成已核实的建筑面积。

既有审计还记录一栋标为小住宅但 assessor Units=4 的样本：`cell_00456 / b5669b59-e639-430f-b565-7ef792c54ef5`。本轮未改标签。应独立复核标签定义及地块到单栋用途匹配，不能根据模型是否答对来改真值。单例冲突也无法解释新模型数千个错误。

## 6. 还有一个独立的覆盖率问题

175 栋缺少成对原生 target/context 输入，占完整 LA 参考集 5.25%，分布在 10 个 cell。既有 `IMAGE_FAILURES.json` 报告 `Missing target or context`。旧 CNN crop/预测仍存在，因此不是完全没有任何图像。

若这些样本始终输出 unknown 并计错，完整集 accuracy 上限为 **94.75%**。解决完整 LA 表现必须同时处理输入覆盖率。

诊断性地仅在这 175 栋使用旧 CNN，其余使用 Qwen zero-shot，完整集 accuracy 可到 97.99%，但 macro-F1 下降到 0.4776，多户仍为 0/14。旧 CNN 在缺失子集上产生 24 个错误，其中 21 个商业误报、3 个多户误报。这个固定 fallback 说明补覆盖并不自动提高分类质量，不应直接作为已验证方案部署；更不能依据这批缺失样本恰好全属小住宅而默认填小住宅。

## 7. 面向 LA 的下一步顺序

1. **明确验收表。** 主报完整 3,332 栋和固定共同子集；同时报告 accuracy、macro-F1、每类 precision/recall、输入覆盖率。改善少数类不能以大量小住宅误报为代价；不把“98% accuracy”单独作为成功。保留 CNN N2 与 Qwen zero-shot 作为固定基线。
2. **先核实难例与训练缺口。** 独立复核全部 14 多户、42 商业及已知冲突，优先补充 LA 或相近成像条件的 4–8 单元低层多户、小型办公室/诊所，并保留相似小住宅作负例。原始参考及结果保持可追溯，任何审定标签另存版本。需要额外属性时，先明确实际推理时是否可用，不用 assessor 真值字段作为测试输入。
3. **首先改进可工作的 CNN 基线。** 继续使用原 Harris+NYC 数据，在空间独立的 LA 开发区补充上述类型，用开发集选采样和阈值。新增训练建筑与原测试建筑、地块及宽视野上下文区域隔离。随后在相同数据、类别定义和训练预算下跑 DINO 对照，才判断是否值得换骨干。LA 三类主评估与五类/角色扩展任务分别验收。
4. **修复输入覆盖并单独评估。** 查清这 10 个 cell 的 target/context 缺失原因；近景有效时的降级方案须在开发集验证，并继续保留完整分母。暂不直接采用上面的 CNN fallback。
5. **保留可信的最终验证。** 当前 LA 已多次查看，之后据此设计方案属于 LA 开发。原集可持续回归比较；另留未看过、空间隔离的 LA 区域作最终确认。无需先跑 Denver 才能改进 LA，但不能将对已查看 LA 的提升写成独立泛化证明。

本轮没有启动以上新训练或采集。优先行动应是 LA 标签/难例与同任务训练对照，暂缓新的城市评测和同配置 QLoRA 扩大实验。
