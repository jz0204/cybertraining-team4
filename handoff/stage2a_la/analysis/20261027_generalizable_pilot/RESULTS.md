# Stage2a 五类泛化 pilot：2026-10-27 结果

**48/48 组完成，但未达到可升级为论文泛化模型的标准。** 按预先约定的城市留出、双种子平均 macro-F1，本轮最高的是冻结 DINOv3-B 的近景方案（0.2669）。它改善了部分城市的住宅/商业区分，NYC 和 San Diego 的多户住宅召回仍为 0；CNN 微调也没有稳定修复这个问题。这里评估的是给定 footprint 的用途分类，不是 detection AP。

DINOv3 已完成账号授权验证、官方权重下载和实际 A30 运算。用户无需继续配置；复用步骤见 [DINOV3_SETUP.md](../../DINOV3_SETUP.md)。模型版本为 `facebook/dinov3-vitb16-pretrain-lvd1689m` @ `5931719e67bbdb9737e363e781fb0c67687896bc`。

这是小规模开发试验：Harris 960、NYC 729、San Diego 101，共 1,790 栋。NYC 中只有 247 栋通过当前官方 footprint/PLUTO 的单建筑、用途及户数一致性核对，训练只使用这部分，评估主表也单列这部分。其标签来自当前 26v2 记录，影像为 2018 年，不能称为影像同期独立 Gold。Harris/SD 仍含来源或弱参考标签。三个城市均为开发数据，没有新独立测试城市。

Harris “主要屋顶”门槛是面积 ≥50m² 且 ≥地块内最大已观测屋顶面积的一半，只作用于训练，保留未筛选的冻结 CNN 对照；它不是经过核实的 primary 标签。不同配方保持相同验证/测试 ID。先将同地块和重叠影像并入空间组，再划分训练/验证。共 29/670/40 个 Harris/NYC/SD 空间组。NYC 的既有影像通常只支持约 130–180m 宽图，真实范围写入数据；没有用放大或补边冒充 300m。

受控双视野比较中，DINO 相对同样主要屋顶筛选的冻结 ConvNeXt，NYC macro-F1 +0.0968、SD +0.0454、Harris −0.0197。空间块 bootstrap 95% 区间分别为 [0.0678, 0.1223]、[0.0074, 0.0881]、[−0.0543, 0.0499]。这些是开发参考标签上的 500 次重采样区间，不覆盖标签错误或新城市变化。完整修复/退步 ID 见 [PAIRED_CONTRASTS.json](PAIRED_CONTRASTS.json)。DINO 加宽图在 NYC/SD 的 macro-F1 反而下降，不能从 Qwen 的上下文收益推断所有视觉编码器也获益。

监督和划分的约束很强：留出 SD 时，过滤后训练集只有 45 个 multi；验证集有 108 个。留出 NYC 时，训练集 47 个 multi、18 个 institutional，验证集只有 1 个 institutional。留出 Harris 时训练集总共 287 栋、multi 22 栋。空间分组会形成不均匀类别分布，主要屋顶筛选还进一步减少训练样本。此次结果不能把监督质量/数量、裁剪与分辨率、视觉可判定性和编码器能力完全分开，更不能代表用全部旧训练数据充分训练后的 CNN 上限。

旧 N1 两个单种子在新近景下均只有 44.59% accuracy；原输入则为 75.68%/77.03%。新近景同时改变物理裁剪、重采样及编码，因此不是只隔离窗口大小的一次实验。这个结果要求后续固定输入管线，不能直接给旧 checkpoint 换图后评价 backbone。当前重训 CNN 双视野的双种子概率均值在 SD 五类上为 57/101（56.44%，macro-F1 0.3079），DINO 近景为 54/101（53.47%，0.3047），此前 Qwen 五类双视野仍较高（63/101，62.38%，0.4676），但 Qwen 的 multi 仍为 0/14，之前角色输出全部 primary。Qwen 使用带目标标记和更高像素输入；此处没有做 Qwen SFT。

拒答也未解决泛化：验证集目标 80% coverage 的 CNN 双视野阈值，在 SD 的实际 coverage 为 46.5%/31.7%，NYC 为 0.4%/20.2%（两个种子）。例如 SD seed43 的 84.38% selective accuracy 仅保留 31.68% 样本，不能报成全量 84.38% 准确率。本轮 48 个新模型均没有角色真值监督，显式返回 role=`unknown`，不评角色准确率。双种子集成没有单独校准，因此不报告集成拒答指标。

下一步应先补足**单栋用途与角色的独立证据**，优先多户主体楼、车棚、住宅外形商业及 institutional，固定物理输入窗口，并保留独立新城。冻结 DINO 可继续作为便宜的特征基线；本轮证据不足以直接换生产模型、扩大 backbone 或投入 RL。VLM SFT/QLoRA 仍是后续竞争方案，应在可靠监督和独立验证准备好后比较。若建筑单元数/用途持续不能从屋顶辨认，再另立高度或街景等额外证据对照。详细预设见 [NEXT_MODEL_PLAN.md](../20261026_generalization/NEXT_MODEL_PLAN.md)。
