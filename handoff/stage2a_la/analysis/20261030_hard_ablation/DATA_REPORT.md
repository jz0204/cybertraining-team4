# 隔离补样批次

冻结45栋4–8户主楼（11个2km网格），6栋混淆独栋（6个网格）。新增多户占地约188–587m²，其中23栋四户、9栋五户、5栋六户、5栋七户、3栋八户；LA训练四户参考由4栋增至27栋。

官方325条多户、554条独栋候选经过单房产建筑数据行、县域单轮廓、楼面/屋顶面积及较新轮廓一致性筛选，留下48多户与103独栋。151套影像获取完整。逐图查看48多户和6条模型混淆独栋，共54条；3条多户因遮挡或复合屋顶归属不清暂缓，其余95条低混淆独栋未作视觉入组审查。逐例证据见REVIEW.csv。

6条负例中1条被两种子均错判为多户，集成多户概率0.911；其余5条为近边界或种子分歧，多户概率约0.402–0.440。它们是官方一户记录及单轮廓支持的主楼，仍不是独立人工金标准。

原31条候选单独保留：两条五户归属尚未解决；28条独栋被模型全部正确识别，不能称为模型难负例。本次未混入这31条。

影像为公开NAIP2022火前RGB，按主瓦片ID锁定并记录拍摄日期，原生0.6m；输出约0.305m用于保持原CNN裁剪物理视野，并不增加真实分辨率。其来源、季节和新街区是本轮完整补样方案的一部分，不能把收益全部归因于样本数量。

原测试全区域2km缓冲、既有验证/预留网格均排除。既有438验证和3332测试的标签及输入完全保留，类/域/多户户数组总采样比例固定。
