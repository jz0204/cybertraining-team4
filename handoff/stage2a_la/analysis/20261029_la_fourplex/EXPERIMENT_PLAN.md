# 四户主楼复核与CNN训练方案

目标：在保持原LA3332测试标签、输入和438验证样本不变的条件下，检验补充小体量多户是否改善多户recall/F1及整体macro-F1。

先逐一检查31个隔离训练区候选，共62个轮廓，结合2024assessor、2014/2020轮廓、火前影像、主建筑面积与屋顶面积关系。不能仅按较大屋顶或整地块4户就赋多户标签；主楼＋非居住附属结构证据一致才纳入主楼，可能是两栋住宅或用途不清者保留unknown。附属结构单独记录，不并入三类用途训练。角色是证据支持的研究标记，非独立人工金标准。

隔离保持旧2km测试buffer、固定train/val/reserved网格及完整上下文约束。候选中28/31在同一网格，须报告空间/形态聚集，不能把新增数量当作同等多样性。

只改训练数据覆盖，重用原N2两个种子的初始化、ConvNeXt-Tiny、RGB+mask+四项几何、area pooling、6轮x8192draws、batch32、lr1e-5、AdamW .01、梯度clip1。用普通LA适配CNN作预算匹配控制，另列原N2与上轮低层重采样结果。

保持source/LA抽样总质量50/50，LA各类总质量仍按上轮478/93/177确定；新增主楼分摊原多户份额，避免把加数据和提高多户类先验混为一项改变。仍由原438验证集采样校正macro-F1选epoch（含0），不用测试选择epoch/阈值。

必须完成：数据/空间/角色审计及冻结→新图真实GPU见证和旧预测复现→CNN42/43→原完整3332及共同3157统一评分→按cell配对bootstrap。主报多户TP/14、FP、precision、recall、F1、整体macro-F1及商业代价；无法改善时如实保留负结果。

使用已授权的短批次服务暂停和自动恢复，启动前检查GPU/磁盘，收集全部预测及权重后独立核验原服务健康。保留旧数据、所有基线、原标签和未用reserved网格。
