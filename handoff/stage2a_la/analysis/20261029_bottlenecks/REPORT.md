# LA识别瓶颈与下一步方法设计

日期：2026-10-29。目标是提高原LA样本上的单栋用途识别，尤其多户recall、F1与整体macro-F1。本轮重算现有预测、检查实际CNN实现、复核35个案例的影像，并核对相关原始论文。没有训练新模型、改测试标签、筛选测试阈值或接触TAMU服务。

当前证据支持优先改善目标细节表示、相似建筑之间的监督和地块到单栋的标签归属。现有模型把部分小体量多户、办公室和诊所当作住宅，同时把外形相似的独栋住宅判成多户。新增加同一街区的样本带来了少量召回改善，也带来更多误报；尚不能证明哪一种新架构能够解决这些问题。

## 1. 同一3332栋上的现状

以下均为已完成的两个种子概率平均结果；本轮没有新增模型成绩。

|模型|Accuracy|Macro-F1|多户TP/14|多户FP|多户recall|多户F1|
|---|---:|---:|---:|---:|---:|---:|
|原N2 CNN|95.83%|0.4833|2|25|14.29%|0.0976|
|普通LA适配CNN|97.72%|0.5716|3|29|21.43%|0.1304|
|低层重采样CNN|97.87%|0.5804|3|27|21.43%|0.1364|
|新增28栋四户CNN|97.42%|0.5679|4|35|28.57%|0.1509|

新模型多户precision仅10.26%。相对普通适配，macro-F1变化−0.0037，配对cell bootstrap 95%区间[−0.0246,0.0322]；多户F1变化+0.0205，区间[−0.0337,0.1200]。没有稳定提升证据。[完整实验结果](../20261029_la_fourplex/REPORT.md)

参考中3276/3332是小型住宅，全部预测小型住宅也有98.32% accuracy，但macro-F1只有0.3305、多户和商业召回均为零。因此主指标应继续是macro-F1、各少数类precision/recall/F1和误报数。这是已给定目标轮廓后的分类评估，不是建筑检测AP。

## 2. 问题分别在哪里

### 目标没有明显裁掉，但表示可能太粗

实际冻结CNN为ConvNeXt-Tiny，RGB+目标mask输入224×224，经backbone得到768×7×7特征；对目标mask内特征做加权平均，再拼接4项几何特征分类。CPU实际前向验证了该尺寸。它的感受野能够看到周围内容，但没有独立的目标近景、邻域关系分支。

10个漏判多户的轮廓面积155–473平方米，目标mask在最后特征图中的面积中位数相当于2.72个网格。14个商业漏判中位屋顶面积207平方米，对应1.74个网格。这里是面积等价网格数，不是独立感受野数量；它说明小目标细节可能被粗化，不能单凭这个数证明模型看不见目标。

这24个漏判的栅格mask面积都没有低于对应轮廓面积的95%，影像复核也未见明显的目标轮廓被裁掉。它们均有近景/宽视野诊断图，已有记录的RGB空白比例均不超过10%。扩大视野未必解决问题；目标归一化近景和中间层较高分辨率特征更值得先做受控对照。放大同一影像不会创造新的原生细节，轮廓完整也不代表轮廓本身正确。

### 主要是细类别混淆，并存在高置信错误

新模型漏判的10栋多户中9栋判住宅、1栋判商业，10次错误的最大softmax概率全部超过90%；35个多户误报中也有11个概率超过90%。只在低最大概率时调用VLM或输出unknown，会漏掉这批高置信错误。softmax数值不能直接当成校准后的正确概率。

多户一对其余类别的classification AP：普通适配0.2223、低层重采样0.1983、DINO适配0.2066、新四户CNN0.2029。新四户CNN的ROC-AUC为0.8658，但提高召回没有同步提高precision或AP。这支持继续检查判别特征和难负样本；不证明任何阈值策略都无效。本轮没有用测试集试阈值。

逐图看到不少四户住宅与一户住宅具有相似的长条坡屋顶、后排停车结构。新增的7个多户误报，官方地块记录均为1户的Single Family Residence，不能简单解释为“小型住宅标签其实都是双拼”。户数及实际办公用途可能无法仅凭屋顶唯一确定。

商业漏判同样有结构：14个中12个为办公或专业服务用途，包括医疗/牙科、兽医等；另2个为商店。LA商业训练177个中仅32个属于前两组，56个面积小于300平方米，面积中位452平方米。漏判商业的面积中位207平方米。应补充小办公室/诊所与相似住宅的成对覆盖；这只是LA训练子集和当前错误的对比，不能替代对全部来源数据的因果归因。

### 样本数增加，但形态和增强多样性有限

新增28栋四户来自同一tract/grid，面积195–254平方米，中位236平方米。独立验证集四户仍为3/10；新纠正的测试四户只被种子42纠正，种子43仍判住宅。增加数量尚未带来稳定的四户区分能力。

还有一个可直接修正的实现限制：本轮实际Dataset的几何增强随机种子由固定dataset seed与样本索引决定。对同一真实训练样本调用20次，得到的输入tensor只有1种。当前domain_augmentation=False、scale_view_probability=0；两次训练也没有把模型种子传给Dataset。重复采样主要重复同一种翻转/旋转，并不产生新的视图。

应先让原有增强随抽样/epoch变化，同时保持可复现；单独控制这个改动。直接开启domain_augmentation还会引入颜色变化，会混淆“修正随机性”和“增加增强种类”两种效果。这是工程基线改进，不是论文创新，也尚未被证明是主要误差原因。

### 误报与数据质量、类别比例也有关

有效训练抽样中多户约10.31%，原采样校正验证中2.75%，本次测试参考中0.42%。三者不同提醒我们关注部署条件下的误报代价；不能把测试比例倒灌为校准参数。校准和选模需要独立、具有代表性的开发区域。

现有近景/宽视野导出不可用的175栋中，多户误报11个；可用的3143个非多户中误报24个，对应6.29%与0.76%。前者48栋的历史RGB空白比例超过10%，但全部35个多户误报只有2个超过该空白阈值，说明不能把全部误报都归因于黑边。导出不可用也不等于CNN没有输入。这是质量分层关联，不是背景缺失的因果证明，不应删除这些样本以提高主结果。

新增误报案例00200_300be333的轮廓在近景中疑似包入泳池/庭院；00218_a20c984b的原CNN图像约33.2%为空白。前者提示上游轮廓污染可能影响几何特征和mask pooling，需要独立核实，不能凭航片印象直接修改轮廓或用途标签。[图像观察记录](VISUAL_REVIEW.md)

### 地块用途仍不完全等于单栋用途

先前官方属性复核的56个少数类与1个矛盾住宅中，4个存在待解决属性问题，其中1个多户有2条assessor building记录。这个已知问题不足以解释其余9个多户漏判。即使只有1条assessor记录，也不保证地块只有1个实际屋顶；新增28主楼+28后排附属结构就是具体例子。

“地块4户”可能是一栋四户楼加车库，也可能是两栋各两户住宅。把地块类别复制给每个屋顶会制造错误监督；把最大轮廓固定当主楼同样不可靠。原3332标签仍保持不变，新建筑级核实应形成另一个有版本的评估集。

## 3. 优先方法与可能的研究贡献

**先完成一个小的表示对照。** 保留CNN，修正动态增强；再比较现有7×7池化与目标近景/较高分辨率中间特征，随后增加一个明确的邻域分支。先验证是否能同时找回多户、减少相似住宅误报。近景必须记录物理尺度，邻域分支保留与目标的空间关系，不能把整条街的用途直接当作目标用途。单纯多尺度融合属于已有方法。

**最值得作为研究主线的是“单栋用途与主/附属角色联合建模，并显式处理地块监督的归属”。** 输入分清目标、邻近建筑和道路/停车关系，输出目标用途及角色；只有已核实的楼栋级标签直接监督用途。地块级记录仅约束允许的楼栋配置，不强迫每个屋顶继承同一标签。无法分配时保留未知。

户数约束必须允许“一栋四户”和“两栋两户”等不同配置。普通正包MIL要求包中至少一个正实例，在后一种情况下不成立。仅凭户数总和也不能唯一识别每栋户数，需要独立楼栋标签和角色锚点；不能把弱监督配置当成新真值。初版先做已核实样本的用途/角色双头及不确定标签屏蔽，只有证明归属问题带来收益后再增加受约束的弱监督。

**配套的是形态相近、用途不同的对照监督。** 在与测试隔离的多街区采集小多户与相似独栋、小办公室/诊所与住宅、主楼与车库，按尺寸和形态配对，并覆盖不同城市。先比较相同训练规模的“新增正例”与“正例+难负例”；必要时再加对比损失。难例采样或对比学习本身也不是新方法。潜在贡献在于是否用正确的证据归属和监督，稳定解决这种城市间可迁移的混淆。

对于航片不足以判断的对象，可检验独立高度、立面或街景的增量价值。VLM适合在有可靠标注时提取可定位的可见属性，或提供额外模态对照；生成的户数、用途解释不能自动充当训练真值。若增加unknown，必须同时报告全样本结果、覆盖率和风险，不能靠剔除困难样本宣称accuracy提升。未经验证的任意背景替换也不能证明模型学到了因果关系。

## 4. 最小实验顺序与验收

|顺序|唯一主要变化|回答的问题|
|---|---|---|
|A0|重用匹配设置的四户CNN作为控制；另保留已有最佳低层CNN作为参照|保证比较基线一致|
|A1|只修正现有增强的随机性和dataset seed|重复采样缺少多样性是否影响结果|
|A2|A1上只改目标尺度/特征分辨率|小目标细节表示是否是瓶颈|
|A3|A2上加独立邻域输入；同时保留target-only对照|背景提供有效证据还是引入地区偏差|
|B1|在胜出的简单架构上，等规模比较正例补充与形态匹配的正负例补充|收益来自数量还是判别覆盖|
|B2|同一组可核实标签上比较用途单头、用途+角色头、弱标签屏蔽；再决定是否做配置约束|角色与监督归属有没有独立贡献|

A组数据、分类标签、训练抽样预算、初始权重来源、种子与选模协议保持一致；不同分辨率同时报告实际时间与显存，避免把更多算力误称方法收益。新模块的初始化须显式记录。先在固定验证集查看多户recall/F1、商业F1与误报，选定方案后在原3332栋做一次冻结回归评估；不依次查看每个变体的测试分数来挑配置。

新的目标近景会改变模型看到的输入，必须另存并保留旧图像；队列/标签不变不等于输入完全相同。纯特征分辨率对照先复用原图，近景输入作为独立变体。不存在的邻域图也要明确可用性和回退策略，不删175个困难对象。

论文验证另需未用于本轮诊断的保留LA区域及至少一个未见城市，独立复核单栋用途和角色，增加少数类样本，按地块/空间块分组。当前14个多户每多识别1栋就改变recall 7.14个百分点，无法支撑精确的提升承诺。原LA可作为固定开发回归集，不能继续称完全盲测。

只有多户F1和整体macro-F1改善、商业表现及误报代价可接受，才值得进入更大的DINO或VLM对照。已有基础模型、上下文图网络、MIL和不完整标签学习均有先例；本轮提出的是待验证研究方向，不是已确认独创的方法。[文献与创新边界](../../../../literature-review/STAGE2A_RECOGNITION_DESIGN_20261029.md)
