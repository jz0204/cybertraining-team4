# 影像驱动的建筑损伤与暴露估计：Stage2a研究判断

2026-10-30（America/Chicago）。本轮为现有结果核查、定向文献检索与方案评估，没有启动训练或替换模型。

## 目标与目前完成程度

可以把目标定义为：**部署时使用带地理配准与尺度信息的灾前、灾后影像，提取建筑实例，估计单栋损伤及潜在暴露，并保留两者的空间对应关系。**

- Stage1从灾前影像得到建筑轮廓；Stage2a使用灾前影像、mask和几何量预测用途及暴露代理；Stage2b使用灾前/灾后影像预测损伤。当前LA完整产品还利用多个灾后日期，不能将其验证成绩写成“一对影像”的性能。
- “影像推理”不等于训练不需要外部资料。现有用途监督来自assessor等记录，人口代理构造使用户数、面积及ACS参数；物理面积也需要影像的地理信息。
- 当前暴露是模型化的exposure proxy。居住人口、商业活动人数、事件发生时在场人数、灾后流离失所人数和伤亡人数不是同一目标。居民暴露与商业暴露应分别定义和验证。
- 最近的CNN实验只训练/评估用途分类。人口头冻结，而且新的用途概率改变了人口模型输入；不能从分类F1改善推导人口或整条流水线已改善。
- 已有独立DINS损伤验证：LA v3 destroyed F1在已检测建筑上为0.958、计入Stage1漏检后为0.862；这是不同于Stage2a 3332条用途参考集的评估，不能拼成联合准确率。

## 证据支持哪些瓶颈

1. **目标表征可能损失细节，但尚未确定为根因。** 11栋漏判面积155–473㎡，9栋为四户；先前正确的3栋多户面积639–2551㎡。CNN最终7×7特征上，漏判mask面积中位数约2.68个等效单元。没有系统性的空白或主屋顶漏裁。DINO更细的token网格未带来可靠优势，因此不能简单断言“7×7造成全部问题”。
2. **形态覆盖仍可能不足，单纯补数量已不足以解释。** 新补45栋包含23栋四户，漏判仍未变；同时新影像是原生0.6m的NAIP，旧LA约0.305m，存在来源/清晰度混杂，不能据此证明补数据无效。
3. **地块监督与屋顶实例之间存在归属缺口。** 四户地块可以是四户主楼加车库，也可能是两栋各两户。把每个屋顶都标成四户会制造错误监督和重复暴露。该问题在数据整理中真实存在，但尚未证明是当前11栋漏判的主要原因。
4. **部分用途可能无法从俯视RGB唯一辨认。** 相似屋顶不能保证分辨内部3户/4户或住宅/住宅式办公室。当前证据还没有测出影像信息上限；模型失败不能单独证明任务不可解。

依据：[逐栋复核](../handoff/stage2a_la/analysis/20261030_multifamily_audit/REPORT.md)、[补样数据说明](../handoff/stage2a_la/analysis/20261030_hard_ablation/DATA_REPORT.md)。

## 推荐路径一：先确定当前CNN是否丢掉了可用视觉信息

固定当前增强、样本、选模区域和物理几何量，按以下顺序做小对照：

- A：现有固定物理窗口。
- B：从原始灾前影像裁出完整目标的自适应近景，保持输入像素预算，检查目标占比和真实原生GSD。
- C：在B上再加入独立的环境视图，复用已有近/宽图数据处理，明确目标mask。环境帮助解释目标，不等于直接继承邻居用途。
- 只有B/C支持该方向，才对照中间层较细特征或保留空间构型的池化，不同时更换骨干、数据与损失。

这是有价值的工程基线。此前DINO近/宽双视图和use/role双头已经运行过；新的实验是**在当前CNN及同一训练数据上隔离输入作用**，不是第一次尝试双视图或角色。裁得更近提高目标在输入中的占比，不创造原图没有的门窗或户数细节。记录单栋推理时延、显存和视图缺失率。

成功标准是独立保留区中4–8户与相似独栋的precision/recall共同改善，并检查商业退化；旧LA3332只作回归诊断。若只再次减少FP而不提高小多户召回，不能宣称解决了目标问题。

## 推荐路径二：把地块户数监督正确归属到建筑实例

候选研究问题：**训练时只有部分地块总户数与少量可靠单栋用途/角色标签，怎样学到可迁移的单栋居住单元分布，并在推理时仅用灾前影像和派生几何？**

最小可检验机制：

1. 保留现有用途头；仅在有可靠监督的样本增加居住单元/居住容量预测，主楼与附属角色是辅助证据。不要把所有附属建筑硬设为0，ADU可能实际居住。
2. 对来源完整、时相一致且确认包含全部相关屋顶的住宅地块，只约束预测居住单元之和匹配该地块的记录总户数；不把总户数复制给每栋。商业Units不直接当居住单元数。
3. 少量独立核实的逐栋户数提供分配锚点；用途/主附属角色标签本身未必足够。四户地块允许(4,0)、(1,3)或(2,2)，总量约束本身无法选出真解；没有锚点时不声称已识别正确归属。
4. 地块边界、assessor户数等只参与训练监督。测试时不输入产生参考标签的字段或派生量，否则应另列辅助数据设定。
5. 由预测单元分布与明确的occupancy假设估计住宅暴露；商业单列。不能把容量预测称为实测人口。

潜在增量是“纠正监督空间单位＋单栋分配可验证＋影像跨区推理”的具体结果。普通MIL、总量loss、双头和概率传播已有先例，不能仅靠组件拼接证明新颖。增加角色头本身也已在本项目试过。

先用相同影像和实际核实成本比较：可靠单栋监督/屏蔽含糊标签；地块标签复制；基础总量回归；带可靠归属锚点的版本。直接监督少量可靠楼栋户数是关键的简单竞争方案。必须单独检查多个屋顶之间的分配错误，不能只报告总户数拟合好。若简单屏蔽含糊标签或直接户数监督已同样好，就保留简单方案，不增加复杂归属模型。

新审阅的结论是 **PROCEED WITH CAUTION**：值得小试，具体薄弱点是总量loss已知、角色标签不保证户数分配可辨识，以及当前漏判机制未被证实。查新初筛记为5/10，按“已有明确近邻、仍有可检验增量”的技能尺度解释，不是发表概率或实验成绩。可检验增量应进一步限定为：在相同核实成本下，利用此前被严格筛掉的多建筑地块，提高未见地区的逐栋户数分配，并保持影像推理。

## 最终验收应回到exposure

现有Harris空间OOF试验的log1p MAE从0.212750降到0.153028，但目标按用途、面积等规则构造；多户RMSE反而从24.06升到26.76。它证明了对该proxy的预测改善，尚未证明真实人口、LA或未见城市的改善。

后续至少保留面积基线、现有soft-type HGB、直接影像回归、候选结构化单元模型。**当前已用soft类别概率，不能把“硬标签改soft”当成新改动。** 用独立核实的楼栋户数验证归属；用未用于监督/校准的细尺度人口参考评估区域人口；区域总数准确不等于单栋分配正确。

首次下游对照固定damage模型，比较同一损伤目标下的暴露误差及高暴露受损建筑漏识别。若只具备proxy，成果仍限定为proxy。目标城市Census校准可以作为单独增强设定，不并入“影像独立推理”的成绩。整体结果还应计入漏检建筑及缺失影像。

## 后续核查：哪些先例真正接近“灾前影像→用途与暴露”

“灾前”通常只是影像采集时间，而不是这些人口/用途方法特有的输入模态。以下多数方法研究普通时相的建筑属性与基础人口分布；接入灾害评估时才能将其作为灾前暴露。不能把“已有相关先例”扩写成“已有模型验证了一张灾前RGB即可准确得到单栋用途和真实人口”。

|工作|已核实的处理路径|关键输入与证据边界|
|---|---|---|
|[Open Data-Driven 3D Building Models for Micro-Population Mapping，Remote Sensing 2024](https://www.mdpi.com/2072-4292/16/21/3922)|日本八王子；融合航片、POI/建筑信息；先区分独栋/非独栋，再区分多户/其他；结合高度/楼层做建筑尺度人口分布|与Stage2a细分用途目标有直接联系；并非纯RGB输入。读取出版方索引的方法和讨论，不据其accuracy声称LA迁移性能|
|[Towards High-Resolution Population Mapping…Bangkok，Remote Sensing 2025](https://www.mdpi.com/2072-4292/17/7/1204)|ResNet-50处理影像，LightGBM处理建筑形状、POI距离、道路等；平均类别概率。ALOS AW3D30经形态学处理估计高度，再按位置/面积/体积/用途等不同方案分配区域人口或户数|使用外部高度、POI、道路、人口资料；核心是属性补全＋人口空间分配，不是单张RGB直接监督真实人数。用途类别也不同于LA三类|
|[POPCORN，RSE 2024](https://arxiv.org/html/2311.14006v2)|冻结的双流U-Net输出built-up score；另一个可训练双流U-Net输出occupancy rate；相乘得到人口图。把格网预测加总到行政区，与Census计算log-L1训练损失|输入Sentinel-1 VV/VH及Sentinel-2 RGB/NIR季节合成；不需要显式用途标签。名义10m计算，最终100m格网；有目标地区Census时可另做总量校准，不能把此设置称为完全无目标人口资料|
|[LandScan mosaic，Scientific Reports 2025](https://pmc.ncbi.nlm.nih.gov/articles/PMC12738844/)|建筑几何、空间分布及邻域形态特征→随机森林用途分布/楼层预测；结合PDT的分用途、分时段occupancy分布进行Monte Carlo；按区域人口校准后汇总|用途与楼层模型主要基于footprint形态特征，而不是原始RGB CNN；occupancy需要外部经验资料。输出分布不自动意味着在LA已校准或精确到单栋|
|[Population Estimation using Deep Learning over Gandhinagar Urban Area，2025非同行评审预印本](https://arxiv.org/pdf/2509.12926)|约0.3m影像建筑patch经CNN分住宅/非住宅；面积与DEM高度等输入ANN回归人口|作者明确没有逐栋人口真值，人口训练目标由面积/高度规则生成。正文与表格对通道数、回归输入/输出等存在不一致，不能把摘要F1当作真实人口验证|
|[POMELO](https://arxiv.org/html/2211.04039v1)|每格MLP从多种协变量预测每栋平均occupancy，与建筑数量相乘；区域总人口弱监督|输入含已有建筑产品、夜光、道路、地形等，输出100m格网；属于多源地理数据人口估计，不应当作“只需一张灾前RGB”的直接例子|

方法启发：可比较“显式用途→人口”和“从影像直接学习occupancy/容量、用途仅作辅助”两种路线。POPCORN证明后一种训练设定已有先例；没有证明把该设定移到本项目就能解决小体量多户、跨城或逐栋人口问题。不同空间粒度、原生分辨率和额外输入的数据不能直接横向比较分数。
